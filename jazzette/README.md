# Jazzette — chapitre 5, « Les tonalités » (prototype)

Web app mobile sans build ni backend. Ouvrir `index.html` via un serveur statique :
`python3 -m http.server -d jazzette 8123`, puis http://localhost:8123 en vue 390 px.

- Progression : `localStorage` (clé `jazzette-ch5-v1`). Menu debug : icône à droite de l'en-tête.
- Réglages à tester dans `app.js` : `SOLID_WINS`, `MEMO_MAX_MISS`.
